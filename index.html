💡 Droit de douane
Un droit de douane est un impôt ou une taxe appliqué sur les biens importés ou exportés. Les droits de douane peuvent être utilisés pour protéger les industries nationales, générer des revenus pour le gouvernement ou influencer les échanges commerciaux.
